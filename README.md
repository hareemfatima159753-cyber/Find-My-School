# Find My School 🏫

> **AI Hackathon Project** | Theme: *AI with Purpose: Building Better Societies*

## 📌 Problem Statement
Navigating educational options can be overwhelming for families, often leading to mismatches in budget, location, and specific learning needs. Equal access to quality education starts with transparent information.

## 💡 Solution
**Find My School** is an AI-powered matching platform designed to help parents and students find schools tailored to their specific financial budget, geographic distance, and educational preferences. 

## ✨ Key Features
- **Smart AI Matching Engine:** Ranks schools based on user-defined criteria (fee range, distance, amenities).
- **Match Score & Analysis:** Provides clear score breakdowns and pros/cons for each recommended school.
- **Direct Demo & Consultation Booking:** Enables instant contact with shortlisted institutions.

## 🛠️ Built With
- HTML5, CSS3 (Tailwind CSS)
- JavaScript (Interactive Logic & AI Scoring)
